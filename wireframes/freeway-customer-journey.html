Customer Journey
How the Freeway screens connect end to end — for the dev building this out. Shows user flow, screen transitions, data passed between steps, and what each screen does.

Landing page

User arrives via referral, social, or direct link. Reads the value prop. Fills out the access request form — first name, last name, email, referred by (required), role, industry.
Founder or employer arrives via referral. Sees the platform positioned for both sides. Fills same form — selects "Hiring / Employer" as role type.

Onboarding
3
Step 03
Voice onboarding — 3 steps
freeway-platform.html
User speaks answers to 3 questions. AI transcribes and extracts positioning in real time. Takes ~2 minutes. Questions: Walk me through your experience · How would you describe yourself and your current role · What are you trying to accomplish
Employer speaks answers to 3 questions about their company, open roles, and what they're looking for. AI extracts company positioning and talent profile.
Voice input → transcript
AI extracts tags
Positioning generated
→ Signal preview
Data passed to next screen: transcript text, extracted keywords/tags, positioning headline → stored in sessionStorage or user profile object
AI processes transcript → generates profile

Step 04
Signal preview — "Here's how we read you"
freeway-signal-preview.html
Dark full-screen reveal. AI shows user their positioning headline, connection tags (keywords), and matched opportunity count. "Thinking" animation → keywords appear → stat cards → CTA to enter dashboard.
Positioning headline shown
Connection tags revealed

Step 05
Home dashboard
freeway-dashboard.html
User's home. One connected block: profile tags at top → "Matched for you" bar with Sort/Filter → 8 opportunity rows → "View all 12" bottom right. Below the block: "Others with your positioning" peer cards.
Employer's home. Profile shows company type and what they're hiring for. Matched talent profiles replace opportunity rows. Same Sort/Filter pattern.

Step 07
Opportunity detail + gap tracker
freeway-opportunity-detail.html
Role-specific detail page. Dark banner shows path: where you are → this role → founding role. Left col: 5-step gap tracker (done ✓, in-progress, gap). Gaps surface Academy bridge cards inline. Right col: role details + Apply CTA.
Gap progress tracker
Academy bridge — inline modules
Apply now
Save role
→ Start module → Academy
Key pattern: Academy is not a separate upsell — it surfaces in context of the gap. "This role needs executive storytelling → Module 1 closes it → Start module" is one inline flow.
